# AutoCut Lab — versões

Instaladores do **AutoCut Lab**, que tira silêncios, respirações e erros de vídeos falados, dentro do Final Cut Pro.

- **Instalar:** baixe o `.dmg` da versão mais nova em [Releases](https://github.com/Final-Cut-Apps/autocut-releases/releases) e siga o "Como instalar.txt".
- **Atualizar:** o AutoCut Lab se atualiza sozinho (Ajustes › Atualizações). Esta página guarda todas as versões, para baixar à mão ou voltar a uma anterior.

Requer Mac com Apple Silicon e macOS 15 ou mais novo. O código do app não fica aqui.
